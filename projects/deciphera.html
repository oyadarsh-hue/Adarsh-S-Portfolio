How it works

STATE INTERPRET EXPLAIN

  1. Simulate a transfer

    A browser-based vUTXO wallet simulates Ark-style shared rounds and off-chain transfers.

  2. Explore the conditions

    A DLC simulator explores collateral conditions, oracle scenarios and Taproot execution paths.

  3. Explain the event

    The Semantic Ledger Narrative engine turns state transitions into human-readable audit narratives.

Features

  • vUTXO transfer simulation
  • DLC covenant scenarios
  • Three levels of narrative detail
  • Interactive script inspection

Outcome

A zero-dependency browser application for exploring and explaining Bitcoin Layer-2 concepts. It is a simulator, not a production financial service.

Engineering challenge

Explaining the same protocol event to different audiences without discarding the underlying technical details.
