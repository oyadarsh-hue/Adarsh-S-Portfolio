AegisForge-X

A multi-language source-security review and symbolic invariant verification platform with cryptographic evidence binding.

Overview

AegisForge-X reviews source code across multiple languages, links findings to exact source positions, performs defensive flow analysis and produces evidence-focused security reports.

Highlights

  • Security review for C/C++, Rust, Go, Python and C#.
  • Defensive taint propagation and symbolic boundary checks.
  • CWE/OWASP/NIST/CERT/CVSS/EPSS mapping.
  • SHA-256 Merkle proof evidence binding and PDF audit output.
